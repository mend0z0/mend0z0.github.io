# Mend0z0 Engineering — Website v2

A responsive static website ready for GitHub Pages. No build process, frameworks, or server required.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services overview
- `pcb-design.html` — PCB Design
- `programming.html` — Programming
- `portfolio.html` — Portfolio (intentionally contains no invented projects)
- `contact.html` — Contact

## Quick start
Open `index.html` in a browser. For a local development server, run `python -m http.server 8000` from this folder and open http://localhost:8000.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root (including `index.html` and `assets/`).
3. In repository Settings → Pages, choose Deploy from a branch, `main`, `/ (root)`.
4. Save; GitHub will provide your Pages URL.

## Before launch
- In `assets/js/main.js`, replace `YOUR_EMAIL@example.com` with your real contact address. The form uses `mailto:` and does not send messages directly from the website.
- Add real portfolio projects when available.
- Review wording, service capabilities, and business contact details.
- Logo and service illustration are supplied by the website owner.

## Design
Colors: deep navy, dark slate, and teal sampled to complement the supplied logo. Hero structure is inspired by the supplied layout reference, not a copy of its branding or text.
